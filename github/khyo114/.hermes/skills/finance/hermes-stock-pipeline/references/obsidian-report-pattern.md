# Obsidian Report Storage Pattern

## Directory Structure

```
주식분석/
├── YYYYMMDD_종합투자분석리포트.md          # 통합 리포트 (전체 종목)
├── {종목명}/
│   └── YYYYMMDD_{종목명}.md              # 개별 종목 리포트
└── data/                                  # 원시 데이터 (선택)
    ├── naver_main_{code}.html
    ├── naver_news_{code}_p1.html
    ├── wisereport_company_{code}.html
    ├── wisereport_valuation_{code}.html
    ├── wisereport_financial_{code}.html
    ├── google_news_{code}.xml
    └── parsed_all.json
```

## File Naming Convention

| 파일 유형 | 패턴 | 예시 |
|-----------|------|------|
| 통합 리포트 | `YYYYMMDD_종합투자분석리포트.md` | `20260816_종합투자분석리포트.md` |
| 개별 리포트 | `YYYYMMDD_{종목명}.md` | `20260816_삼성전자.md` |
| 원시 데이터 | `{source}_{code}.{ext}` | `naver_main_005930.html` |
| 파싱 데이터 | `parsed_{code}.json` | `parsed_005930.json` |

## 🎯 주요 투자 포인트

### 강점 (Bull Case)
1. **메모리 사이클 턴어라운드** - DDR5/HBM 수요 급증으로 실적 개선 기대
2. **AI 반도체 수혜** - HBM3E 양산으로 엔비디아 등 대형 고객 확보
3. **파운드리 적자 축소** - 4/3nm 수율 개선, 외부 고객 확대
4. **주주환원 정책** - 분기배당 유지, 자사주 매입/소각 지속

### 약점 (Bear Case)
1. **메모리 가격 변동성** - 공급 과잉 시 실적 급락 리스크
2. **파운드리 경쟁 심화** - TSMC 독주, 인텔/삼성 격차 확대
3. **지정학적 리스크** - 미중 반도체 전쟁, 중국 수출 규제
4. **성장 둔화** - 스마트폰/PC 수요 정체, 교체 주기 장기화
